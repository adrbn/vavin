## Changes

- **"Vavin" is now a Reserved Font Name**, declared in `OFL.txt` and in the copyright string (name ID 0) of every
  font. You may still modify and redistribute the fonts under the SIL Open Font License 1.1, but a modified version
  must be published under another name (OFL clause 3).
- **Vavin Display Black** has its own legacy family name, "Vavin Display Black", plus typographic family and
  subfamily names. Windows no longer sees two fonts called "Vavin Display Regular".

Outlines, metrics and character set are unchanged from 1.0.

## In the zip

`Vavin-v1.1.zip` holds `ttf/`, `app/` (Latin subset) and `web/` (WOFF2) for each of Vavin, Vavin Condensed and
Vavin Display, plus `OFL.txt` and `FONTLOG.txt`.
